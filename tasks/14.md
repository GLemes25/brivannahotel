# Contexto e Objetivo

Você atuará como Engenheiro de Software Frontend. O objetivo dessa tarefa é refatorar a camada de dados (mock/static data) do projeto.
Atualmente, temos arquivos `.json` e `.ts` separados dentro de várias subpastas no diretório `src/app/data/` (ex: `indications/`, `feedbacks/`, `regulations/`).

Queremos simplificar essa estrutura:

1. Eliminar todos os arquivos `.json`.
2. Transferir os dados estáticos diretamente para arquivos `.ts` como constantes exportadas (ex: `export const feedbacksData = [...]`).
3. Eliminar todas as subpastas dentro de `src/app/data/`, deixando todos os arquivos `.ts` na raiz da pasta `data/`.
4. Atualizar as importações em todos os componentes que consumiam esses dados.

## 1. Nova Estrutura Desejada

A pasta `src/app/data/` deve ficar plana (flat), contendo apenas arquivos TypeScript. Exemplo do que deve ser feito:

- **Brivanna:** `data/brivanna.json` vira `data/brivanna.ts` (exportando `brivannaData`).
- **Feedbacks:** `data/feedbacks/feedbacks.json` e o tipo exportado viram apenas `data/feedbacks.ts` (exportando `feedbacksData`).
- **Regulations:** `data/regulations/regulations.json` vira `data/regulations.ts`.
- **Indications:** `data/indications/indications.json` e `data/indications/categories.ts` devem virar `data/indications.ts` (exportando `indicationsData` e `CATEGORIES` no mesmo arquivo, ou em arquivos separados na raiz da pasta `data`).

## 2. Padrão de Conversão (Exemplo)

**Antes (JSON):**

```json
[{ "id": "1", "name": "Exemplo" }]
```

**Depois (TypeScript):**

```typescript
export const indicationsData = [{ id: "1", name: "Exemplo" }];
```

_(Certifique-se de tipar os arrays e objetos usando os `types` já existentes, exportando-os se necessário para uso nos componentes)._

## 3. Atualização das Importações (Refactoring)

Após converter os arquivos e mover tudo para a raiz de `src/app/data/`, você deve varrer os componentes do projeto (ex: `CategoryPage.tsx`, `Footer.tsx`, `Feedbacks.tsx`, etc.) e corrigir os imports.

**Exemplo de correção:**
_De:_ `import indicationsData from "@/app/data/indications/indications.json";`
_Para:_ `import { indicationsData } from "@/app/data/indications";` (ou o nome do arquivo ts correspondente).

## 4. Regras Estritas de Execução (NÃO NEGOCIÁVEIS)

1. **Mantenha a integridade dos dados:** Nenhum texto, link, horário ou id deve ser perdido na conversão de JSON para TS.
2. **Limpeza de Diretórios:** Apague rigorosamente os arquivos `.json` originais e as subpastas vazias (`indications`, `feedbacks`, etc.) dentro de `app/data/` após a migração.
3. **Zero Erros de Tipagem:** Garanta que os componentes que consumiam os JSONs continuem funcionando perfeitamente. Se o componente esperava uma tipagem específica, certifique-se de que o novo `.ts` a forneça.
4. Não adicione comentários como `// arquivo refatorado`. Apenas entregue o código limpo.

## Instrução de Ação

Execute a leitura da pasta `src/app/data/`. Converta todos os JSONs em arquivos `.ts` na raiz desta pasta. Apague as subpastas e os arquivos JSON antigos. Em seguida, atualize todas as rotas de importação no projeto para apontarem para a nova estrutura.

**Dica para a execução:** O Claude Code é excelente em fazer refatorações em lote, mas recomendo que você faça um **commit (commit no git)** antes de rodar o comando. Assim, se ele modificar algo que quebre o build, você pode reverter facilmente.
