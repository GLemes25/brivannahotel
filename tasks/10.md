# Contexto e Objetivo

Você atuará como um Engenheiro de Frontend Sênior e especialista em UX/UI de luxo. Seu objetivo é atualizar o componente `CategoryPage.tsx` e refatorar o arquivo `app/data/indications/indications.json` para calcular e exibir dinamicamente o **Status de Funcionamento (Aberto, Fechado, Fecha em breve, 24h)** em tempo real.

## 1. Refatoração do Arquivo JSON (`indications.json`)

O JSON atual possui a string `"businessHours"` (para exibição) e um inútil `"isOpenNow": true` (estático).
Você DEVE remover o `"isOpenNow"` de todos os itens e criar uma nova propriedade `"schedule"` que possa ser lida pelo código (usando `dayjs` ou `Date` nativo).

**Exemplo do formato exigido para o `"schedule"` no JSON:**
Deve mapear os dias da semana (0 = Domingo, 1 = Segunda, ..., 6 = Sábado) ou definir se é 24h. Lembre-se de tratar casos que passam da meia-noite (ex: 17h às 01h).

```json
// Exemplo 1: Horário normal
"businessHours": "Seg a Sex · 6h às 22h · Sáb e Dom · 8h às 18h",
"schedule": {
  "1": { "open": "06:00", "close": "22:00" },
  "2": { "open": "06:00", "close": "22:00" },
  "3": { "open": "06:00", "close": "22:00" },
  "4": { "open": "06:00", "close": "22:00" },
  "5": { "open": "06:00", "close": "22:00" },
  "6": { "open": "08:00", "close": "18:00" },
  "0": { "open": "08:00", "close": "18:00" }
}

// Exemplo 2: Passa da meia noite (Bar do Mané)
"businessHours": "Qua a Dom · 17h às 01h",
"schedule": {
  "3": { "open": "17:00", "close": "01:00" },
  "4": { "open": "17:00", "close": "01:00" },
  "5": { "open": "17:00", "close": "01:00" },
  "6": { "open": "17:00", "close": "01:00" },
  "0": { "open": "17:00", "close": "01:00" }
}

// Exemplo 3: 24 horas
"businessHours": "Aberto 24h",
"schedule": { "is24h": true }

```

Atenção: Atualize todos os itens do arquivo indications.json seguindo essa lógica com base na string businessHours já existente lá.

2. Função de Status Dinâmico (No Componente)
   Em CategoryPage.tsx, crie um hook ou função auxiliar (ex: useBusinessStatus(schedule)) que rode no client-side. Use dayjs para retornar um dos seguintes status, baseando-se na hora atual do usuário:

"24H": Se schedule.is24h for true.

"OPEN": Se o horário atual estiver dentro da janela open/close.

"CLOSING_SOON": Se estiver dentro da janela de funcionamento, mas faltar menos de 60 minutos para o horário close.

"CLOSED": Se estiver fora do horário de funcionamento ou se não houver expediente no dia atual.

3. Design System: Indicadores Visuais (Padrão Premium)
   Posicione a informação de status e horário logo acima da linha divisória dourada (<div className="w-16 h-[1px]..." />). O design deve ser minimalista, sem badges gritantes.

"Aberto" ou "Aberto 24h" (Status: OPEN / 24H):

Dot (bolinha): bg-emerald-500/80.

Texto: "Aberto agora" ou "Aberto 24h" em text-xs font-light text-emerald-400/80.

"Fecha em breve" (Status: CLOSING_SOON):

Dot: bg-amber-500/80

Texto: "Fecha em breve" em text-xs font-light text-amber-400/80.

"Fechado" (Status: CLOSED):

Dot: bg-rose-500/50.

Texto: "Fechado" em text-xs font-light text-rose-300/50.

Exibição do Horário (businessHours): \* Ao lado do status, adicione um bullet point (•) e o texto do businessHours com as classes text-xs text-muted-foreground font-light tracking-wide.

4. Regras Estritas de Código (NÃO NEGOCIÁVEIS)
   Zero Comentários: O código final não deve ter nenhum comentário (// ou {/\* \*/}).

Zero Inline Styles: É expressamente proibido o uso de style={{...}}.

Tipografia (Regra da Serifa):

font-serif SOMENTE para Títulos principais e botões.

Textos auxiliares, tags, horários e descrições usam fonte sem-serifa com font-light e tracking-wide.

Preservação: Mantenha a estética de luxo, as cores douradas (#ca993d), os filtros de tags (se houver), e o layout expandido com a numeração gigante em background.

Instrução de Execução
Reescreva o arquivo indications.json aplicando a nova propriedade "schedule" em todos os objetos e removendo "isOpenNow".

Atualize o CategoryPage.tsx implementando a lógica de tempo real e os indicadores visuais premium.

Retorne os códigos completos sem pular nenhuma parte.
