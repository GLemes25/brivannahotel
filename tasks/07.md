# TASK: Refatorar Regulations para Full-Page Section e Fix de Layout Horizontal

Preciso refatorar o conjunto de componentes em `app/components/regulations/` para que a seção ocupe a tela inteira (Full Page) no desktop e seja 100% responsiva no mobile, sem gerar scroll horizontal.

## Arquivos Alvo:

- `app/components/regulations/Regulations.tsx`
- `app/components/regulations/RegulationSection.tsx`
- `app/components/regulations/RegulationItem.tsx`

## 1. Estrutura Global (Regulations.tsx):

- Remova seções aninhadas. Utilize apenas uma `<section>` principal com `min-h-screen` e `flex flex-col justify-center`.
- O contêiner principal deve ser `max-w-7xl` para alinhar com o componente de quartos.
- O Grid deve ser `grid-cols-1 md:grid-cols-3` com `gap-0` e `divide-x` (apenas no desktop) para criar divisórias verticais simétricas.

## 2. Componente de Seção (RegulationSection.tsx):

- **Alinhamento Desktop:** No desktop, todos os elementos devem estar centralizados horizontalmente (`items-center` e `text-center`).
- **Ícone:** O componente `Image` deve manter `width={100}` e `height={100}`, sem fundo, centralizado, com a animação de hover já existente.
- **Espaçamento Intemo:** Use paddings laterais generosos (ex: `md:px-12`) para criar o efeito de "respiro" entre o texto e as divisórias. No mobile, garanta que o padding não cause overflow (`px-6`).
- **Rigor Visual:** - O título deve ter uma altura mínima (`min-h`) para garantir que os conteúdos abaixo comecem na mesma linha.
  - O `highlight` deve ser forçado em uma única linha (`truncate` ou `whitespace-nowrap`).

## 3. Prevenção de Overflow (Mobile):

- Garanta que o componente pai tenha `overflow-x-hidden`.
- Verifique se não há larguras fixas em pixels (como `w-[600px]`) que quebrem o layout em telas menores. Use larguras relativas ou `max-w-full`.
- No mobile, o layout deve converter para uma lista vertical simples (`flex-col`) com `divide-y`.

## 4. Estilo:

- Mantenha a paleta de cores e fontes Serif/Sans conforme definido em `.claude/rules` e no seu `globals.css` (tema Dark fixo).
- Use `framer-motion` para entrada suave dos itens.
