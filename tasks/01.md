# 🧩 TASK 01: HotelRules (Refatoração UI + Arquitetura)

## 🎯 Objetivo

Criar componente de regras do hotel com visual inspirado no layout enviado:

- Fundo **verde escuro**
- Título com **gradiente vermelho**
- Layout em **linhas (não colunas)**
- Destaque visual em **multas e taxas**
- Ícones via **imagem (URL ou local)**
- Dados vindos de **JSON em `/data`**
- Componentização máxima

---

## 📁 Estrutura

```
/components/hotel-rules/
  HotelRules.tsx
  RuleSection.tsx
  RuleItem.tsx

/data/hotel-rules.json
/types/hotel-rules.ts
```

---

## 🧠 Regras técnicas

- Arrow functions
- Usar `type`
- Separar: UI / data / types
- Sem hardcode no componente
- Ícones via `next/image`

## 🚫 Não fazer

- Não usar grid
- Não usar lucide
- Não usar fundo claro

- Não deixar texto sem hierarquia

## ✅ Resultado esperado

- Visual semelhante ao exemplo enviado
- Estilo premium (hotel real)
- Forte contraste (escuro + destaque)

- Ícones grandes ajudam leitura rápida

- Mobile continua em coluna (ícone em cima se necessário)
