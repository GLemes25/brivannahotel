# Contexto e Objetivo

Você atuará como Desenvolvedor Frontend e Especialista em Rastreamento de Dados (MarTech). O objetivo é implementar o disparo de eventos do Meta Pixel no projeto Next.js do Brivanna Hotel.

**Cenário Atual do Negócio:**
O site funciona como uma vitrine de conversão. Quando o usuário clica no botão "Reservar", ele é enviado para um **link externo** (um Motor de Reservas de terceiros). Portanto, não temos o evento final de "Compra" no nosso domínio, apenas a intenção de reserva (clique de redirecionamento).

## 1. Implementação Técnica (Código)

Crie snippets de código limpos e adaptados para o Next.js (App Router):

1.  **Topo de Funil (Todos que entram):** Disparo base do evento genérico `PageView` em todas as páginas (assuma a criação de um componente cliente de rastreamento no `layout.tsx`).
2.  **Meio/Fundo de Funil (Intenção de Reserva):** Atualize as funções de clique/redirecionamento dos botões "Reserve agora" (do Header, do Hero e Mobile). Ao clicar, **antes** de abrir o link externo, o código deve disparar: `fbq('track', 'InitiateCheckout', { content_name: 'Redirecionamento_Motor' })`.

_Atenção SSR:_ Lembre-se de validar `typeof window !== 'undefined'` para não quebrar a hidratação do Next.js. Não altere os estilos Tailwind ou lógicas originais dos botões.

## 2. Geração do Manual Estratégico de Marketing

Após gerar o código, escreva um **Manual de Rastreamento e Estratégia (Formato Markdown)** direcionado à equipe de Marketing / Tráfego Pago do hotel.
Explique em linguagem de negócios:

1.  **O Funil do Site Oficial:** O que significam os eventos implementados (`PageView` para todos os visitantes e `InitiateCheckout` para quem clicou para ir ao motor).
2.  **A Ponte de Dados (Ponto Crítico):** Explique claramente que, como a reserva é finalizada em um sistema externo, o time de marketing DEVE configurar o ID do Pixel do Facebook diretamente nas configurações desse Motor de Reservas de terceiros para capturar o evento `Purchase` (Compra) e o valor em R$ (ROAS).
3.  **Sugestão de Estratégias de Remarketing:** Formule 2 estratégias de anúncios utilizando o "abandono de intenção" (pessoas que dispararam `InitiateCheckout` no site, mas não dispararam `Purchase` no motor).

## 3. Regras Estritas de Execução (NÃO NEGOCIÁVEIS)

- O código TypeScript gerado deve ser limpo e sem comentários gerados (`//`).
- O documento de marketing deve ser persuasivo, profissional, sem jargões de programação (ex: não mencione SSR, Hooks ou Next.js no manual deles) e pronto para ser copiado e enviado por e-mail/WhatsApp para a equipe de marketing.
