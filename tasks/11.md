# Contexto e Objetivo

Você atuará como Engenheiro de Frontend Sênior. Sua tarefa é adicionar um novo status de tempo real ("Abre em breve") ao componente `CategoryPage.tsx`, complementando a lógica de horários que você acabou de implementar.

## 1. Nova Lógica de Status ("Abre em breve")

Atualize a função que calcula o status do estabelecimento (ex: `useBusinessStatus` ou similar) para suportar o estado `OPENS_SOON`.

A nova lógica deve avaliar a hora atual:

- Se o estabelecimento está `CLOSED` (Fechado) agora, mas o horário atual for **menor ou igual a 60 minutos antes** do horário de abertura (`open`) do dia atual, o status deve ser **`OPENS_SOON`**.

_Atenção:_ Lembre-se de tratar a virada do dia, caso o estabelecimento abra muito cedo ou tenha fechado após a meia-noite.

## 2. Design System: Indicador Visual "Abre em breve"

O novo indicador deve usar nossa cor de destaque (`#ca993d`) para criar uma sensação de expectativa positiva, mantendo o padrão premium.

Adicione este bloco à renderização condicional dos status:

- **Status "Abre em breve" (OPENS_SOON):**
  - Dot (bolinha): `bg-[#ca993d]/80`.
  - Texto: "Abre em breve" em `text-xs font-light text-[#ca993d]`.
  - Exibição do Horário (`businessHours`): Ao lado, exiba o bullet `•` e a string do horário normalmente (`text-xs text-muted-foreground font-light tracking-wide`).

## 3. Regras Estritas de Código (NÃO NEGOCIÁVEIS)

1.  **Zero Comentários:** O código final não deve conter nenhum comentário gerado.
2.  **Harmonia Visual:** Mantenha a nova tag exatamente na mesma linha e alinhamento que as tags de "Aberto" e "Fechado".
3.  **Clean Code:** Não altere a lógica das tags (`tags`), do filtro ativo, ou a formatação do "fecha em breve" (`CLOSING_SOON`) já existentes. Apenas adicione a nova verificação `OPENS_SOON`.

## Instrução de Execução

Analise a função de cálculo de horário no `CategoryPage.tsx`. Implemente o status `OPENS_SOON` e a UI correspondente em dourado (`#ca993d`). Retorne apenas o código completo e finalizado do componente `CategoryPage.tsx`.
