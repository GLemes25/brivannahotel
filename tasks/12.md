# Contexto e Objetivo

Você atuará como um Engenheiro de Frontend Sênior especializado em UX/UI de luxo. Seu objetivo é atualizar a navegação global do site nos componentes `Header.tsx` e `Footer.tsx`.

A página inicial (`Home`) é composta pelos seguintes componentes (e IDs correspondentes):

- Hero (`hero`)
- BookingWidget (`booking-widget`)
- About (`about`)
- Agreement (`agreement`)
- Rooms (`rooms`)
- Regulations (`regulations`)
- Location (`location`)
- Feadbacks (`feedbacks`)
- Parking (`parking`)
- Indications (`indications`)

## 1. Atualização do `Header.tsx`

O Header atual está incompleto. Você deve atualizar as opções de navegação (tanto na versão Desktop quanto no menu Mobile) para incluir todas as seções relevantes, na seguinte ordem e com os seguintes labels em Português BR:
**Início** (ID: `hero`)
. **Sobre** (ID: `about`)
. **Convênio** (ID: `agreement`)
. **Quartos** (ID: `rooms`)
. **Regras** (ID: `regulations`)
. **Localização** (ID: `location`)
. **Avaliações** (ID: `feedbacks`)
. **Estacionamento** (ID: `parking`)
. **Indicações** (ID: `indications`)
exclua **Contato**

_Atenção (UI do Header):_

- Se a quantidade de links no Desktop ficar muito densa e quebrar o layout, reduza o espaçamento (`space-x-8` para `space-x-4` ou `space-x-6`) ou diminua levemente a fonte, mantendo a harmonia.
- Mantenha o CTA "Reserve agora" intacto.
- Gere a lista de links mapeando um array (ex: `const NAV_LINKS = [...]`) para não repetir código (DRY), tanto no mobile quanto no desktop.

## 2. Atualização do `Footer.tsx`

O Footer atual possui uma coluna "Links Rápidos" que precisa ser atualizada para refletir a mesma navegação do Header.

- Mapeie o mesmo array de links (ou similar) utilizado no Header.
- Garanta que a capitalização (ex: "Localização", "Guia Local") seja feita corretamente na exibição, sem depender de lógicas complexas no JSX. Sugestão: o array já deve conter `{ id: 'rooms', label: 'Quartos' }`.

## 3. Regras Estritas de Código (NÃO NEGOCIÁVEIS)

1.  **Zero Comentários:** O código deve estar 100% livre de comentários (`//` ou `{/* */}`).
2.  **Zero Inline Styles:** Proibido usar `style={{...}}`. Todo o estilo, inclusive tipografia (ex: font-size, font-weight), DEVE ser refatorado para as classes utilitárias do Tailwind CSS (ex: `text-[15px] font-normal`).
3.  **Tipografia e Cores (Padrão Luxo):**
    - Links normais do Header/Footer devem usar fonte sem-serifa (padrão), pesos leves (`font-light` ou normal), e cores que indiquem interatividade sutil (ex: hover para o dourado `#ca993d` ou `text-primary`).
    - Mantenha a cor primária dourada.
4.  **Preservação:** Mantenha as animações do Framer Motion, a lógica do `useEffect` de scroll e o acionamento do mobile menu inalterados, além dos dados consumidos do arquivo JSON no Footer.

utilize tambem as regras em .claude/rules

Refatore e atualize os componentes `Header.tsx` e `Footer.tsx` aplicando as novas listas de navegação completas e convertendo todos os estilos inline para Tailwind. Retorne os dois códigos completos.
