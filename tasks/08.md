# TASK: Criar Ecossistema "Indicações Brivanna" (Concierge Digital)

Precisamos substituir o antigo componente `Indications.tsx` por um sistema dinâmico completo de guia local, seguindo as regras em `.claude/rules`. O código deve usar nomenclatura em inglês para variáveis/arquivos.

## 1. Fonte de Dados (`app/data/indications/indications.json`):
Crie um JSON robusto com as seguintes categorias (slugs): `laundries`, `burger-joints`, `restaurants`, `pizzerias`, `tourist-spots`, `supermarkets`, `pharmacies`, `airport`, `gyms`, `bars`.
Cada local dentro do JSON deve ter:
- `id`: string
- `name`: string
- `categorySlug`: string
- `description`: string (curta e atrativa)
- `distance`: string (ex: "2.5 km" ou "400 m")
- `instagramUrl`: string (link simulado)
- `mapUrl`: string (link simulado para traçar rota)

## 2. Componente de Vitrine (`app/components/indications/Indications.tsx`):
- **Objetivo:** Uma seção "Full Page" (min-h-[80vh]) elegante e sem rolagem vertical desnecessária.
- **Header:** Título "Indicações Brivanna" (com tipografia Serif premium) e subtítulo "Sinta-se um morador local. Nossas recomendações exclusivas para sua estadia."
- **Grid de Categorias:** Crie um grid compacto (ex: `grid-cols-2 md:grid-cols-3 lg:grid-cols-5 gap-3 md:gap-4`).
- **Cards (Tiles):** Minimalistas. Em vez de cards grandes, use "Tiles" ou "Botões Grandes". 
  - Fundo translúcido (`bg-white/5` no hover muda para `bg-[#ca993d]/10`).
  - Um ícone Lucide **pequeno e elegante** (size 20 ou 24) no topo ou ao lado, com o nome da categoria.
  - Ao clicar, deve usar o componente `<Link>` do Next.js para navegar até `/indications/[category]`.

## 3. Rota Dinâmica (`app/indications/[category]/page.tsx`):
- Crie a página da categoria específica usando os dados do JSON.
- **Layout:** Header limpo com um botão de "Voltar" (lucide: ArrowLeft) e o título da categoria selecionada.
- **Lista de Locais:** Um grid `grid-cols-1 md:grid-cols-2 lg:grid-cols-3` de cards para cada local.
- **Card do Local:** - Nome (Serif) e Descrição.
  - Badge minimalista indicando a distância.
  - **Ações (Botões):** 1. Um botão primário "Traçar Rota" (ícone de mapa/navegação) apontando para o `mapUrl`.
    2. Um botão secundário (outline) "Instagram" (ícone de Instagram ou link externo) para ver o visual do lugar.

## 4. UI/UX e Estilização (Premium Dark Theme):
- Use `framer-motion` para transições suaves entre as interações.
- Garanta que no mobile a renderização dos botões das categorias fique perfeita (textos não podem quebrar feio, use tamanhos de fonte ajustados `text-sm` ou `text-xs` nos botões se necessário).
- Utilize a cor primária `--primary` (`#ca993d`) estrategicamente nos hovers, ícones ativos e badges.

Concentre-se em um código limpo, componentizado e pronto para produção B2B/Premium.
