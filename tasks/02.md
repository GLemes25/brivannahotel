Atue como um Engenheiro Front-end Sênior especialista em Next.js, React e UX/UI para conversão.

Preciso que você crie um novo componente chamado `<BookingWidget />` (e seus subcomponentes necessários) que funcionará como o motor de reservas do site do meu hotel. Este componente ficará posicionado logo abaixo do `<Hero />` na página principal (geralmente sobrepondo levemente a base do Hero com margem negativa para um efeito flutuante elegante). Ele deve seguir estritamente as regras definidas nos arquivos `.claude/rules`.

**1. OBJETIVO DO COMPONENTE:**
O componente deve coletar parâmetros do usuário através de uma UI limpa e luxuosa, e ao clicar em "BUSCAR QUARTOS", deve redirecionar o usuário (via `window.open` em nova aba ou `router.push`) montando uma URL com query parameters complexos.

**2. ESTRUTURA DA URL DE DESTINO (EXEMPLO ALVO):**
`https://reservas.bitzsoftwares.com.br/9968eeee-f170-4705-b665-4939c0b92c73/pt-BR?dataCheckIn=2024-04-28&dataCheckOut=2024-05-30&adultos=2&criancas=2&idadeCriancas=[2,14]&quartos=[{"id":1,"adultos":2,"criancas":2,"idadeCriancas":[12,13]},{"id":2,"adultos":1,"criancas":0,"idadeCriancas":[]}]&promotionalCode=JK89JX0`

**3. TIPAGEM E ESTADO (TypeScript Estrito):**
Crie as interfaces necessárias para gerenciar este estado complexo. O estado raiz deve conter:

- DateRange (Check-in e Check-out)
- Array de Quartos (onde cada Quarto tem um ID, contador de adultos, contador de crianças e um array com as idades dessas crianças).
- Cupom de Desconto (string).
  Os totais gerais de `adultos`, `criancas` e o array geral de `idadeCriancas` da URL devem ser calculados dinamicamente com base no array de quartos antes de montar o link.

**4. UI E COMPORTAMENTO DOS CAMPOS:**
O design deve ser uma barra horizontal no desktop, com fundo claro/branco, bordas arredondadas e sombra suave. No mobile, os campos devem empilhar verticalmente.
Divida o código em subcomponentes para manter a manutenibilidade:

- **Campo 1: Datas da Estadia (`<DateRangeSelector />`)**
  - Um botão/input que abre um Calendário (use `react-day-picker` se for padrão Shadcn, ou simule a estrutura de um Popover de calendário). Deve permitir selecionar uma data de início e uma de fim.

- **Campo 2: Quartos e Hóspedes (`<GuestRoomSelector />`) - _O MAIS COMPLEXO_**
  - Um botão que exibe o resumo (ex: "2 Quartos, 3 adultos, 2 crianças").
  - Ao clicar, abre um `Popover` ou `Dropdown`.
  - Dentro do Popover: Deve listar cada quarto adicionado.
  - Para cada quarto: Botões de `+` e `-` para Adultos e Crianças.
  - Se o número de crianças no quarto for maior que 0, deve renderizar dinamicamente `Selects` ou `Inputs` para que o usuário informe a idade de cada criança daquele quarto específico (como mostrado na interface de referência).
  - Rodapé do Popover com botão para "Adicionar Quarto" e botão "Concluído".
  - Opção de "Remover" cada quarto (exceto o Quarto 1).

- **Campo 3: Cupom de Desconto**
  - Input de texto simples com um ícone de presente (`Gift` do lucide-react).

- **Botão de Ação: "Buscar Quartos"**
  - Botão com forte peso visual (use as cores do padrão do site). Ao clicar, deve validar se as datas foram preenchidas, construir a URL codificada corretamente e redirecionar.

**5. REGRAS DE ESTILIZAÇÃO E ANIMAÇÃO:**

- Use Tailwind CSS.
- Use `framer-motion` para suavizar a abertura do dropdown de hóspedes e a aparição dos campos de idade das crianças.
- Mobile First: Em telas pequenas, garanta que os popovers ocupem a tela de forma amigável para o toque (touch targets grandes).
- Adicione um ID id="booking-widget" na div raiz para que o Header possa rolar até ele.

Gere o código completo do `<BookingWidget />` e seus subcomponentes auxiliares no mesmo arquivo ou na estrutura de pastas correta para o App Router.
