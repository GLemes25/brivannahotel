# Contexto e Objetivo

Você atuará como um Engenheiro de Frontend Sênior e especialista em UX/UI de luxo. Seu objetivo é atualizar o componente `CategoryPage.tsx` e a tipagem do `indications.json` para suportar e exibir o **Horário de Funcionamento (Business Hours)** e o **Status Atual (Aberto/Fechado)** de cada local.

utilize as regras do .claude/rules

## 1. Atualização do Modelo de Dados

Assuma que o tipo `Indication` receberá uma nova propriedade para os horários.
Adicione a tipagem necessária para suportar algo como:
`businessHours: string` (Ex: "Ter a Dom - 18h às 23h")
`isOpen: boolean` (Assuma que a lógica de validação de horário pode ser feita no componente ou que o JSON já traga horários estruturados. Para simplificar a UI agora, crie um mock ou uma função simples usando `dayjs` para determinar se está aberto ou fechado no momento, ou aceite um booleano provisório `isOpenNow` na tipagem para renderização).

## 2. Design System: Status Aberto/Fechado (Padrão Premium)

A indicação visual de "Aberto/Fechado" deve ser extremamente elegante e sutil. Evite cores neon ou badges gigantes que quebrem a harmonia escura e dourada.

- **Posicionamento:** Coloque a informação de horário e status logo abaixo do título e das tags, antes do divisor dourado (`<div className="w-16 h-[1px]..." />`), ou alinhado com a `Badge` de distância.
- **Status "Aberto" (Open):** \* Use um indicador visual minimalista, como um pequeno "dot" (ponto) verde muito suave: `bg-emerald-500/80`.
  - Texto: "Aberto agora" em fonte leve (`font-light`), tamanho pequeno (`text-xs`), cor `text-white/70`.
- **Status "Fechado" (Closed):**
  - Conforme a paleta premium, o vermelho deve ser contido e elegante. Use um tom de rose acinzentado ou vermelho bem escuro/translúcido.
  - Dot: `bg-rose-500/50` ou `bg-neutral-500`.
  - Texto: "Fechado" com a cor `text-white/40` ou `text-rose-300/50`.
  - Opcional: Mostrar "Abre às Xh" ao lado em tom neutro.
- **Horário de Funcionamento (Texto):** Exiba a string do horário (ex: "18:00 - 23:30") ao lado do status, separado por um bullet (`•`), usando `text-muted-foreground` e `font-light`.

## 3. Regras Estritas de Código (NÃO NEGOCIÁVEIS)

1.  **Zero Comentários:** Remova e evite adicionar QUALQUER comentário (`//` ou `{/* */}`) no código gerado. O código deve ser autoexplicativo.
2.  **Zero Inline Styles:** Proibido o uso de `style={{...}}`. Toda estilização deve usar utilitários Tailwind CSS.
3.  **Tipografia (Regra da Serifa):** \* `font-serif` estritamente para Títulos, Labels, e Botões Principais.
    - Textos de descrição, horários e status devem usar a fonte padrão (sem serifa), com classes como `font-light` e `tracking-wide` para leitura limpa.
4.  **Preservar Layout Atual:** Mantenha a estrutura editorial com o número "marca d'água" gigante ao fundo do card, o glassmorphism (`bg-card/5 backdrop-blur-xl`), os hover effects em dourado (`#ca993d`) e os botões de ação exatamente como estão.
5.  **Clean Code:** Mantenha `"use client";` no topo e remova imports não utilizados.

## Instrução de Execução

Analise o componente `CategoryPage.tsx` atual. Atualize a interface e as tipagens para integrar a exibição de horário de funcionamento e a badge de status (Aberto/Fechado) seguindo a estética de revista de luxo exigida. Trate casos onde a informação de horário não exista (renderização condicional). Retorne apenas o código completo e finalizado do componente.
